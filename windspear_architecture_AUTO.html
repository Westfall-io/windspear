Processing Flow

Step 1: Git repository is cloned and switched to the target branch/commit

Step 2: Jupyter notebooks containing SysML are discovered, assembled, and executed via Papermill

Step 3: Parsed models, elements, requirements, verifications, and actions are stored in PostgreSQL

Step 4: Webhook notification is sent to WINDSTORMHOST marking the commit as processed
